# Magic 8-Ball: The Pixel Oracle
Interactive Python game built for fast decision-making, reading into the future, and having fun.

## Features
-User Input

-Random Engine

-Conditional Logic

## Getting started
### Libaries
Python |
Tkinter and ttk |
Pillow (PIL) |
Tkinter Canvas and after () |
pytest |
Pyinstaller

### Prerequisites
Check for requirements

Download code

Run the application

### Execution
* Type your name then press enter
* Type your question then press enter
* Press "ASK THE 8-BALL" button
